# Scheduled Wardrobe Agent & Reminders

This repository contains the consolidated scheduler for your daily style checks, clothing deals hunting, and ABA therapy reminders. It is designed to run automatically in the cloud 24/7 using GitHub Actions.

## 📂 Repository Contents
* `scheduler.py`: The Python runner that evaluates cron schedules, runs the style/deal agents via the Gemini API, scrapes DuckDuckGo, and triggers Telegram/WhatsApp notifications.
* `jobs.json`: The scheduled jobs catalog defining cron rules and payloads.
* `closet.json`: Your professional clothing inventory.
* `latest_clothing_deals.md`: Curated shopping sales, automatically generated by the Evening Deal Hunter.
* `.github/workflows/schedule.yml`: GitHub Actions schedule configuration (running every 30 minutes).

## 🚀 Setup Instructions

Follow these steps to deploy and run your agent online:

### 1. Create a Private GitHub Repository
1. Go to [GitHub](https://github.com/) and create a new repository.
2. Name it (e.g., `wardrobe-agent`).
3. Set the visibility to **Private** to keep your inventory, state, and logs private.
4. Leave it empty (do not initialize with a README, `.gitignore`, or license).

### 2. Push Your Code to GitHub
Open your terminal in this directory and run the following commands to link and push your code:
```bash
# Rename default branch to main (if not already)
git branch -M main

# Link to your new repository (replace USERNAME and REPO-NAME with your GitHub details)
git remote add origin https://github.com/USERNAME/REPO-NAME.git

# Push the code
git push -u origin main
```

### 3. Add GitHub Repository Secrets
To run securely in the cloud without committing credentials, add the following secrets in your GitHub repository:
1. Navigate to your repository page on GitHub.
2. Go to **Settings > Secrets and variables > Actions**.
3. Click **New repository secret** and add:
   * `GEMINI_API_KEY`: Your Google Gemini API Key.
   * `TELEGRAM_BOT_TOKEN`: Your Telegram Bot API token.
   * *(Optional)* `WHATSAPP_ACCESS_TOKEN`: Your Meta Graph API WhatsApp token.
   * *(Optional)* `WHATSAPP_PHONE_NUMBER_ID`: Your Meta WhatsApp Phone Number ID.
   * *(Optional)* `WHATSAPP_TO`: Your default WhatsApp recipient phone number (including country code).

### 4. Enable Workflow Write Permissions
Since the scheduler commits its running state (`scheduler_state.json`) and clothing deals (`latest_clothing_deals.md`) back to your repository:
1. In your GitHub repository, go to **Settings > Actions > General**.
2. Scroll down to **Workflow permissions**.
3. Select **Read and write permissions**.
4. Click **Save**.

## 🛠️ Local Testing & Development

You can run jobs manually from your terminal for testing:

```bash
# Run the scheduler normally (checks schedule)
python scheduler.py

# Force run the Evening Deal Hunter immediately
python scheduler.py --run-deal-hunter

# Force run the Daily Style Check immediately (sends Telegram/WhatsApp)
python scheduler.py --run-style-check
```
